## 先看账单：OSS的钱花在哪两项上

决定买什么包之前，先弄清楚账单结构。OSS的常规费用集中在两块：**存储费**（按存的容量和存储类型算）和**流量费**（公网流出按GB算，00:00–08:00闲时约0.25元/GB，08:00–24:00忙时约0.50元/GB）。增值项如传输加速、图片处理，不开通不计费。

免费的部分容易搞混：开通OSS服务、创建Bucket、上传文件的流入流量、同地域ECS通过内网Endpoint读取OSS，这些都不要钱。所以账单基本只由两件事决定——存了什么，以及谁在通过公网下载。

请求费用按API调用次数收，单次极低，日常规模基本可以忽略；只有海量小文件加高并发的场景才会累积成看得见的数字。

判断方法很简单：在费用中心打开OSS的明细账单，看哪个计费项金额最高，就针对那一项买包。存储费高买存储包，外网流出高买下行流量包。账单大头是流量却买了一堆存储包，是新手最常见的失误——存储包一分钱流量费都抵不了。

## 存储包怎么选：先对齐Bucket类型，再定容量

存储包选购的顺序很重要：先确认类型能对上，再谈容量和价格。顺序反了，便宜就变成了浪费。

### 存储包类型必须和Bucket一致，否则一分钱都抵扣不了

存储包按“存储类型+冗余类型”组合售卖。Bucket创建时选的是本地冗余（LRS），就买X-本地冗余包；选的是同城冗余（ZRS），就买X-同城冗余包。这个对应关系错了，资源包完全用不上。

这种错比想象中普遍。有开发者买了2TB标准本地冗余包，结果Bucket用的是同城冗余，整包闲置；还有人买了归档包，Bucket里根本没设归档类型。下单前花一分钟确认两件事：Bucket的存储类型（标准/低频/归档）、冗余类型（本地/同城），然后买完全一致的包。

### 数据的温度决定包的类型

五种存储类型按访问频率从高到低排：标准、低频、归档、冷归档、深度冷归档。按量单价（中国大陆、本地冗余、官方折扣口径）大约是：标准0.09元/GB/月，低频0.07元，归档0.03元；同城冗余的标准存储约0.12元/GB/月。以控制台实时单价为准。

便宜的类型都有附加条件：低频最短存储30天，读取收数据取回费；归档最短60天，读取前要先解冻，时间从分钟级到小时级；冷归档和深度冷归档最短180天，解冻更慢。数据隔三差五要读的话，这些隐性成本会把省下的存储费吃回去。

判断原则：每月至少被访问一次的数据放标准；备份、历史数据放低频或归档；确定长期不动的合规留存数据才进冷归档。拿不准访问频率时，先用标准存储，再配生命周期规则让数据自动降温——比如满30天转低频、满180天转归档。有公开案例靠这套规则把单位存储成本降到原来的27.5%左右。

归档还有一个容易被漏掉的计费细节：**按单个文件最小64KB计费**。海量小文件直接转归档，等于为大量不足64KB的空额付费，先把小文件打包成大文件再归档才划算。

### 容量按“近3个月平均用量+增量”定

统计过去3个月的平均存储量，加上未来半年的预期增量，选略高于这个数的规格。买远超用量的包，没用完的额度不退；缺的部分走按量，单价也贵不到哪去。

价格上，资源包的优惠机制是“买5送1、买9送3”：半年付付5个月的钱，年付付9个月的钱，相当于列表价打75折左右。实际能省多少，取决于你账号的按量单价——按量按0.12元/GB/月算，100GB包年付99元对比按量一年144元，省三成；按量单价已经是折扣价0.09元/GB/月的话，对比是108元对99元，省得有限。下单前用自己账单里的实际单价算一遍，比看任何广告都准。

## 资源包能抵什么、不能抵什么

资源包只抵扣对应的计费项：存储包只抵存储容量费，不覆盖流量费、请求费和图片处理等数据处理费用；下行流量包只抵公网流出流量，内网流量本来免费，不需要包覆盖。想清楚这一点，“该买哪种包”就不再是玄学——账单哪项高，包就买哪种。

多种存储产品混用的团队还有一个灵活选项：存储容量单位包（SCU）。一份SCU额度可以抵扣OSS、NAS等多种云存储产品的按量账单，比单买多种专属包更灵活。只用OSS的话，直接买OSS资源包通常更划算。

## 这几种情况会让资源包白买

下面这些坑，每一个都有真实账单为此买单：

1. **包类型和Bucket不匹配**。本地冗余的包抵不了同城冗余的桶，归档的包抵不了标准类型的文件。下单前核对两遍。
2. **账单大头是流量，却只买存储包**。图片、视频类业务流量费超过存储费很常见，存储包再大也压不住。
3. **同地域ECS走了公网Endpoint**。明明在同一机房，却因为用了公网地址按外网流出计费。改成内网Endpoint，这部分流量直接归零，开发阶段最容易漏。
4. **小文件进归档**。归档按最小64KB计费，几KB的日志文件、缩略图直接转归档，等于为凑不满的空额付费。
5. **数据还热就转低频或归档**。提前删除要按最短存储时长补费，读取还要付取回费、等解冻。转存之前先确认数据真的冷了。

## 常见问题

### 资源包和按量付费能同时用吗？

能。买了包之后，包内额度先抵扣，超出部分继续按量计费，两种模式一直共存。比较稳的用法是：OSS先按量跑一两个月，账单稳定后再按实际用量买包。

### 存储包买大了能退吗？

多数资源包在未使用的情况下支持5天无理由退款，超过5天按剩余量折算，具体以购买页展示的退款规则为准。另外，升级后的包不能降配，规格别一次跳太大。

### 流量包快用完了怎么办？

流量包不支持升级，直接再买一个相同地域、相同类型的包叠加即可，两个包同时抵扣额度。

### 低频和归档的隐性成本有哪些？

三块：最短存储时长（低频30天、归档60天、冷归档和深度冷归档180天），提前删除按最短时长补费；数据取回费，读取就收；归档和冷归档读取前要先解冻，等待时间从分钟到小时不等。频繁读取的数据放这两个类型，反而更贵。
